🦯 Divyanjan AI Assistant – Drishti Mithra
An AI-powered visual assistance system for visually impaired and Divyangjan users that uses computer vision, speech recognition, OCR, translation, and navigation technologies to help users understand and interact with their surroundings independently.
📌 Overview
Divyanjan AI Assistant (Drishti Mithra) is a voice-controlled assistive application designed to provide real-time environmental assistance.
The system can:
👁️ Detect objects using YOLO
📖 Recognize text using OCR
🗣️ Accept voice commands using speech recognition
🔊 Provide spoken responses using Text-to-Speech
🌐 Translate recognized text/responses into different languages using Google Translator
🗺️ Provide navigation and location-based assistance using maps
🚧 Assist users in identifying obstacles and objects in their surroundings
